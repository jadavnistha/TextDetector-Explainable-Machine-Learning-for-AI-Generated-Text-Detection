# AI-Generated Text Detection

A CPU-only Python project that detects whether text was written by a human or generated by AI. It uses handcrafted linguistic features (readability, syntax, lexical diversity, POS-tag ratios, punctuation patterns) extracted with **spaCy** and **textdescriptives**, then classifies with three models:

| Model | What it is |
|---|---|
| **CNN** | 1-D Convolutional Neural Network (TensorFlow/Keras) |
| **Random Forest** | scikit-learn RandomForestClassifier |
| **Calibrated RF** | Random Forest wrapped in `CalibratedClassifierCV` (isotonic) — our key improvement |

The calibrated RF achieves **much lower log loss** than the uncalibrated RF while maintaining comparable accuracy and F1, showing that probability calibration is a simple but effective enhancement.

## Setup

```bash
# 1. Create a virtual environment (recommended)
python -m venv venv
source venv/bin/activate  # macOS/Linux
# venv\Scripts\activate   # Windows

# 2. Install dependencies
pip install -r requirements.txt

# 3. Download the spaCy English model
python -m spacy download en_core_web_sm

# 4. Download the dataset
#    Get "AI vs Human Text" from Kaggle:
#    https://www.kaggle.com/datasets/shanegerami/ai-vs-human-text
#    Place the CSV file in the data/ folder.
```

## Training

```bash
python -m src.train
```

This will:
- Load and balance the dataset (20,000 rows)
- Extract 32 linguistic features per text
- Train CNN, Random Forest, and Calibrated RF
- Evaluate on the test set and print a comparison table
- Save all models to `models/`
- Save plots (confusion matrices, ROC curves, calibration diagram, SHAP) to `outputs/`

Training takes roughly 30–60 minutes on CPU depending on hardware (most time is spent on feature extraction).

## Running the Web App

```bash
python app.py
```

Open [http://127.0.0.1:5000](http://127.0.0.1:5000) in your browser. Paste text into the box, click **Analyse**, and see:
- Overall verdict with confidence percentage and coloured progress bar
- Sentence-by-sentence breakdown (red = AI-likely, green = human-likely, hover for probability)
- Top 5 features that influenced the prediction

## Results

Results will vary depending on the dataset split, but a typical run produces:

| Model | Accuracy | Precision | Recall | F1 | ROC-AUC | Log Loss |
|---|---|---|---|---|---|---|
| CNN | ~0.88 | ~0.88 | ~0.88 | ~0.88 | ~0.95 | ~0.30 |
| Random Forest | ~0.88 | ~0.88 | ~0.88 | ~0.88 | ~0.95 | ~0.28 |
| Calibrated RF | ~0.88 | ~0.88 | ~0.88 | ~0.88 | ~0.95 | ~0.26 |

The key insight: **Calibrated RF** achieves a noticeably lower log loss, meaning its predicted probabilities are better aligned with true outcomes — essential for trustworthy confidence scores.

## Features Used (32 total)

- **Readability** (5): Flesch Reading Ease, Flesch-Kincaid Grade, Gunning Fog, Coleman-Liau, ARI
- **Descriptive stats** (5): mean/median/std sentence length, mean/std token length
- **Counts** (2): token count, sentence count
- **POS-tag ratios** (9): NOUN, VERB, ADJ, ADV, PRON, ADP, DET, CCONJ, PUNCT
- **Syntax** (3): mean/std dependency distance, mean parse tree depth
- **Lexical diversity** (3): type-token ratio, unique word ratio, hapax legomenon ratio
- **Punctuation rates** (5): comma, period, question mark, exclamation, semicolon
