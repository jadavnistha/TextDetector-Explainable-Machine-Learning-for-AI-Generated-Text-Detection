About the Project

How We Detect AI Text

An explainable, CPU-only approach to AI-generated text detection using handcrafted linguistic features and calibrated machine learning models.

Methodology

Instead of using large transformer models that require GPUs and act as black boxes, this project takes a different approach. We extract 32 interpretable linguistic features from each text using spaCy and textdescriptives, then classify using traditional machine learning models.

This makes every prediction explainable — you can see exactly which features (readability, sentence structure, vocabulary patterns) contributed to the decision.

Feature Categories

Category Count Examples
Readability 5 Flesch Reading Ease, Gunning Fog, Coleman-Liau Index
Descriptive Stats 5 Mean/median/std sentence length, mean/std token length
Counts 2 Total tokens, total sentences
POS-Tag Ratios 9 NOUN, VERB, ADJ, ADV, PRON, ADP, DET, CCONJ, PUNCT
Syntax 3 Mean/std dependency distance, mean parse tree depth
Lexical Diversity 3 Type-token ratio, unique word ratio, hapax legomenon ratio
Punctuation Rates 5 Comma, period, question mark, exclamation, semicolon

Models

1-D CNN

TensorFlow / Keras

Convolutional neural network operating on the feature vector. Two Conv1D layers with batch normalisation, followed by dense layers with dropout regularisation.

Random Forest

scikit-learn

Ensemble of 100 decision trees. Strong baseline with good accuracy, but predicted probabilities tend to be poorly calibrated (clustered near 0 and 1).

Calibrated Random Forest

scikit-learn + CalibratedClassifierCV

Same Random Forest wrapped in isotonic regression calibration (5-fold CV). Achieves similar accuracy but significantly lower log loss, meaning the confidence percentages are more trustworthy.
